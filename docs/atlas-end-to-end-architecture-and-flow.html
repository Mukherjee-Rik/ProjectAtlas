01 System Hierarchy & Data Isolation

Project Atlas enforces a hierarchical multi-tenant structure designed for independent restaurant scalability, multi-branch expansion, and total data isolation across tenants.

PLATFORM ADMIN (Global Infrastructure, Global Monitoring, Support Desk, Subscription Tiers) └── TENANT (Billing Organization, Subscription Account, Master Owner) └── RESTAURANT (Concept Branding, Master Menu, AI Copilot, Automation Rules) └── BRANCH (Physical Location, Local Inventory, Operating Hours) └── DINING AREA (Floor Plan Section: Indoor, Rooftop, Courtyard) └── TABLE (Unique QR Session Token `tbl_xxxx`, Real-time Cart) └── ORDERS & PAYMENTS (KDS Pipeline: PENDING ➔ PREPARING ➔ READY ➔ SERVED ➔ COMPLETED)

🛡️ Multi-Tenant Guards

Every API route enforces TenantAccessGuard, RestaurantAccessGuard, and BranchAccessGuard. Cross-tenant leakage results in immediate HTTP 403 Forbidden.

⚡ Session QR Engine

Tables have encrypted public tokens (e.g., tbl_33c549...). Customers order directly without requiring mobile app downloads or logins.

🧠 Autonomous AI Brain

Integrated conversational copilot and scheduled cron automations actively analyze revenue, low stock, and peak sales hours.

2

Step 2: Digital Menu Exploration & Customization GUEST / DINER

Step 3: Shared Table Cart & Order Placement GUEST / DINER

Step 4: Live Order Tracking & Service Calls GUEST / DINER

GET/v1/public/tables/:token/orders/:id POST/v1/public/tables/:token/call-waiter

05 Floor & Kitchen Operations Workflow

Real-time synchronization across Kitchen Display Systems (KDS), Waitstaff floor terminals, and Cashier POS settlement counters.

Stage Interface / Route Actor Operational Action & State Transition
1. New Order Ticket /kitchen (KDS) Kitchen Expeditor / Chef Audio chime triggers. Ticket arrives under PENDING with table number, quantities, and dish notes.
2. Cooking in Progress /kitchen (KDS) Line Chef Chef clicks "Start Cooking". Ticket moves to PREPARING. Prep timer begins tracking kitchen efficiency.
3. Food Plated & Ready /kitchen (KDS) Line Chef Chef clicks "Ready for Pickup". Ticket transitions to READY. Waitstaff terminal receives visual notification.
4. Table Delivery /waiter (Floor App) Floor Waiter Waiter picks up hot dishes, delivers to table, and marks ticket SERVED.
5. Bill & Settlement /cashier (POS) Cashier / Manager Cashier reviews table total, applies discounts, processes Payment (Cash, UPI QR, Card POS), and marks order COMPLETED.

07 Production Resilience & Disaster Recovery

🔒 Multi-Tenant Security Guarantees

1. Zero Cross-Tenant Leakage: Every query in Prisma includes where: { restaurantId, tenantId } automatically scoped by JWT context.
2. Token Integrity: Cryptographically signed JWT access tokens with rotating refresh cookies and instant token blacklisting.
3. Rate Limiting & DDoS Shield: Tiered Redis rate limiters protecting public QR endpoints (100 req/min) and internal APIs (1000 req/min).

📦 Automated Relational Backups

Execute full snapshot drills using pnpm db:backup. Snapshots 13 core relational tables and runs automated foreign key referential integrity checks before saving to encrypted storage.

🔄 Zero-Downtime Rolling Restarts

Docker Compose healthchecks ensure new API containers are fully warmed and passing PostgreSQL / Redis readiness probes (/health/ready) before traffic is cut over.
